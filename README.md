# Chronological Bible Engine

A polished, "headless" scripture reading environment built with React 18 and Tailwind CSS. This engine separates the presentation layer from the content, allowing for a dynamic, immersive reading experience of the Protestant Bible in chronological order.

**Key Features:**

* **Chronological Navigation:** A custom calendar system designed for a 365-day reading plan.

* **Linguistic Substitution:** Toggle between Traditional and Modernized keywords, and view Divine Names in English, Transliterated Hebrew, or Original Hebrew.

* **Deep Study Tools:**

  * **Recursive Tokenization:** Handles nested linguistic tags (e.g., Divine Names inside Strong's definitions).

  * **Inline Lexicon:** Clickable Strong's numbers with a slide-out definition panel.

  * **Bible Atlas:** Interactive book and chapter navigation.

* **Immersive UI:**

  * Glassmorphism aesthetics with "Parchment" reading surface.

  * Dark/Light mode support with distinct celestial animations for Divine Names.

  * Responsive design for mobile, tablet, and desktop.

* **Zero-Build Architecture:** Runs entirely in the browser via a single HTML file (with external JSON data silos), making it perfect for GitHub Pages or local network hosting.

**Technology Stack:** React 18, Tailwind CSS, Babel Standalone.
